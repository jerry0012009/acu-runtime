Optional video reading (downloaded only during explicit setup)

claude-video-vision 1.4.0 by Jordan Vasconcelos, MIT
Source: https://github.com/jordanrendric/claude-video-vision
The unchanged npm distribution and its LICENSE are retained under the
current-user ACURuntime/video-reading directory. ACU adds a visual-only
MCP launcher; it does not replace the upstream decoding implementation.

Node.js 24.22.3, MIT and bundled third-party licenses
Source: https://nodejs.org/dist/v24.22.3/
The official distribution's LICENSE is retained in the private node directory.

FFmpeg / FFprobe (platform binaries supplied by @ffmpeg-installer/ffmpeg 1.1.0
and @ffprobe-installer/ffprobe 2.1.2)
Sources: https://github.com/ffmpeg-installer/ffmpeg-installer
         https://github.com/descriptinc/ffprobe-installer
         https://ffmpeg.org/
Builds have platform-specific LGPL/GPL terms. Their packages, provenance and
license/readme files remain beside the downloaded binaries in node_modules.
These executables are separate processes, not linked into ACU Runtime.
Source and build links: https://github.com/ffmpeg-installer/ffmpeg-installer#custom-builds
                       https://github.com/descriptinc/ffprobe-installer

Magpie
Source: https://github.com/yetone/magpie
Pinned kernel release and isolated UI integration: v0.1.4096
The runtime reuses an existing executable when available. Development
installers bundle a verified CLI executable from the release above.
Upstream source assets used for isolated integration tests are not bundled here.
